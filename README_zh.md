# 🚀 Qwen 自动化 v1.0.2 - chat.qwen.ai AI 自动化 [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**Qwen 自动化** 是一款强大的生产力工具，用于在 Qwen AI (`chat.qwen.ai`) 上自动化您的创作流程。告别手动逐个复制和输入提示词——实现流程自动化，排队数十或数百个提示词，大规模生成视频和图片。

-----

## ✨ 主要功能

* **🚀 批处理：** 排队大量提示词，让扩展程序自动运行发送、生成并处理整个自动化过程。
* **🧩 工作流（可视化拖放编辑器）：** 在画布上连接提示词、图片和生成节点——例如先生成图片，再自动用这些图片生成视频。可保存多个工作流，运行单个节点或全部运行，并以文件导入/导出。
* **🎬 文本生成视频自动化：** 自动将文本描述转换为高质量视频。
* **🎬 帧图生成视频（图片转视频）：** 使用静态图片作为输入，并使用提示词添加自动运动效果以创建动态视频。支持仅使用起始帧，或使用起始帧和结束帧。
* **🎬 素材生成视频：** 每个提示词支持上传多达 10 张素材图片，以生成丰富的复合动画视频。
* **🖼️ 文本生成图片批处理：** 批量生成多张高质量图片，支持各种常用宽高比。
* **🖼️ 图片生成图片：** 使用 AI 和自定义提示词转换和增强现有图片。
* **⚙️ 专业自动化控制：**
    * **并发提示词数：** 同时处理多个提示词以节省时间，加速您的工作流程。
    * **随机延迟：** 在提交提示词之间设置智能间隔，以优雅地应对速率限制（rate limits）。
    * **自动下载：** 生成完成后自动下载图片和视频。
    * **自动更改文件名：** 根据配置自动对下载的文件进行重命名。
* **📊 侧边栏队列监控：** 在 Chrome 侧边栏中通过活跃队列、延迟倒计时和直观的状态栏实时监控进度。
* **📂 有序文件管理：** 按您的项目将下载的文件自动分类到不同的子文件夹。
* **🌐 多语言支持：** 英语、越南语、中文、韩语、西班牙语、日语。

## 📖 使用指南

### 开始使用

1. **访问 Qwen AI**
   - 打开 [chat.qwen.ai](https://chat.qwen.ai) 页面。
   - 确保您已登录您的 Qwen 账号。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标。建议固定以便快速访问！
   - 此时将打开扩展程序侧边栏。

3. **配置批量设置**
   - 在 **控制** 标签页中，您可以设置 **保存到文件夹** 的名称以整理您的下载文件。
   - 在 **设置** 标签页中，自定义您的 **并发提示词数**、**随机延迟**、模型选择以及自动下载选项。

4. **选择模式**
   - 点击模式按钮之一：**文本生成视频**、**帧图生成视频**、**素材生成视频**、**文本生成图片** 或 **图片生成图片**。

---

### 各模式使用说明

#### 1. 文本生成视频模式
1. 选择 **文本生成视频** 模式。
2. 在输入框中输入提示词（每个提示词之间用 **空行** 分隔）。
3. 或者点击 **上传 .txt 文件** 或 **上传 .xlsx / .csv** 来导入提示词列表。
4. 点击 **运行** 开始批量生成视频。

**示例提示词：**
```
雪地里一间舒适的木屋，里面有温暖的炉火正劈啪作响。
摄像机缓慢穿过窗户。

高科技科幻指挥中心，全息图在黑暗中发光。
全息地图的特写镜头。
```

#### 2. 帧图生成视频模式
1. 选择 **帧图生成视频** 模式。
2. 拖放或点击上传您的源图片。
3. 输入提示词（用空行分隔）。
4. 在设置中配置使用 **每个提示词仅使用起始帧** 或 **每个提示词使用起始帧和结束帧**。
5. 点击 **运行**。

#### 3. 素材生成视频模式
1. 选择 **素材生成视频** 模式。
2. 上传多张素材图片（每个提示词最多 10 张）。
3. 勾选 **自动添加角色图片**，系统将自动根据文件名与提示词中的角色名称进行匹配并添加。
4. 输入提示词（用空行分隔），然后点击 **运行**。

#### 4. 文本生成图片模式
1. 选择 **文本生成图片** 模式。
2. 输入详细提示词（用空行分隔）。
3. 在设置中配置所需的 **默认宽高比**。
4. 点击 **运行**。

#### 5. 图片生成图片模式
1. 选择 **图片生成图片** 模式。
2. 上传您想要修改或增强的源图片。
3. 输入描述修改或风格调整的提示词。
4. 点击 **运行**。

### 🧩 工作流（可视化拖放编辑器）

工作流是用于多步骤流程的可视化拖放编辑器——例如：先生成几张图片，再用这些图片生成视频，然后用另一个提示词延续每个视频。它在独立窗口中打开，并在您已打开的 chat.qwen.ai 标签页上运行。

#### 打开工作流

* 在控制标签页中点击 **工作流**（最下面一排按钮）。
* 已在侧边面板输入提示词或上传图片？将鼠标悬停在 **工作流** 上并点击 **转换为工作流**：提示词、每个提示词的模式和图片都会变成工作流中的节点，可直接运行。

#### 界面

| 区域 | 内容 |
| :--- | :--- |
| **左侧** | **节点**（点击或拖到画布上）和 **我的工作流**（已保存的工作流列表） |
| **顶部栏** | 画布工具：撤销/重做、**自动排列**、适应视图、**示例**、清空。右侧：**详情** 按钮、**快捷键** 和 chat.qwen.ai 标签页状态 |
| **画布** | 您的节点。左上角：**全部运行**（运行时还有 **停止**）和 **开启后台模式** |

**详情** 按钮提示需要注意的情况：有问题阻止运行时显示红色/黄色的 **问题 (n)**，生成时显示 **运行中 3/8**。点击可打开面板，查看问题（点击问题跳到对应节点）、进度、运行计划及所用设置。

#### 节点

| 节点 | 作用 |
| :--- | :--- |
| **输入提示词** | 一个或多个提示词，用 **空行** 分隔 |
| **上传图片** | 您的图片（可直接把文件拖到节点上）。悬停图片：🔍 放大查看，✕ 删除，拖动角上的手柄可调整顺序。顺序（或排序菜单）决定每个提示词使用哪张图片 |
| **生成图片** | 文本生成图片；连接图片后为图片生成图片。选项：**每个提示词的图片模式**、**每个提示词的最大输入图片数**、**自动添加角色图片** |
| **生成视频** | 文本生成视频；连接图片后为 **帧图生成视频** / **素材生成视频**。选项：**每个提示词的视频模式**、每个提示词的图片数（与侧边面板设置共用）、**自动添加角色图片**（素材生成视频） |

生成节点会根据第一个提示词自动命名（`image_…` / `video_…`）。每行提示词都会显示它将使用的图片，方便运行前检查。预览区域采用设置中的 **宽高比**（9:16 的节点更窄更高）。

#### 连接节点

从节点右侧的圆形连接点拖出，**放到另一个节点的任意位置**——会自动选择合适的输入口。拖动时，可以连接的节点会高亮。

| 从 | 到 | 含义 |
| :--- | :--- | :--- |
| 输入提示词 | 生成图片 / 生成视频 | 要生成的提示词 |
| 上传图片 | 生成图片 / 生成视频 | 参考图、起始帧或素材 |
| 生成图片 | 生成图片 / 生成视频 | **生成的图片** 作为该节点的输入（图片就绪后才运行） |
| 生成视频 — **最后一帧** 输出 | 生成视频 | 后一个视频 **从前一个视频的最后一帧继续** |
| 生成视频 — **最后一帧** 输出 | 生成图片 | 每个视频的 **最后一帧** 作为输入图片（视频就绪后才运行） |

#### 运行

* **全部运行**（左上角，或 `Ctrl/⌘ + Enter`）按正确顺序运行整个工作流：需要生成图片的节点会在图片就绪后自动开始。
* 如果 **全部运行** 不可用，顶部栏会显示 **问题 (n)**：点击查看需要修复的内容。
* 每个生成节点都有自己的 **运行** 按钮，只运行该节点。在其依赖的节点完成之前按钮不可用（悬停可查看原因）。
* **停止** 取消仍在运行的任务。
* 运行时，连向正在生成的节点的连线会发光并流动，让您看到工作流进行到哪一步。

> ⚠️ **chat.qwen.ai 标签页不可见时 Chrome 会暂停它**（例如工作流窗口全屏遮住它时）。点击 **开启后台模式**（工作流中 **全部运行** 按钮下方，或侧边面板中），然后在 Chrome 的对话框中选择 chat.qwen.ai 标签页。这会共享 chat.qwen.ai 标签页（不会录制或发送到任何地方），让它在其他窗口后面继续生成。绿色的 **后台运行中** 标识表示已开启；点击 ✕ 关闭。

#### 结果

结果直接显示在生成节点中。悬停结果：🔍 放大查看，✕ 删除（橡皮擦按钮清除该节点的全部结果）。悬停时视频自动播放。文件仍会照常下载。

下一个节点使用 **每个提示词的第一个结果**。要换成别的结果，拖动结果左上角的手柄放到另一个结果上即可交换位置（图片和视频均可）。

#### 管理工作流

在左侧的 **我的工作流** 中：**新建**、**导入**，以及每个工作流的 **⋯** 菜单——**重命名**（或双击名称）、**复制**、**导出**、**删除**。所有更改都会自动保存。

* **导出** 会下载一个 `.json` 文件。文件开头有 `//` 注释行，描述所有节点、属性和连接方式，因此您可以把文件交给 AI 助手，让它编写新的工作流。导入时会自动去掉这些注释行。
* 用 **导入** 按钮导入文件，或直接 **把 `.json` 文件拖到画布上**。

#### 编辑快捷键

点击顶部栏的 **快捷键**（或按 `?`）查看全部快捷键。

| 操作 | 按键 |
| :--- | :--- |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` |
| 复制 / 剪切 / 粘贴节点（也可粘贴到其他工作流） | `Ctrl/⌘ + C / X / V` |
| 复制一份所选节点 | `Ctrl/⌘ + D` |
| 全选 / 加选 / 框选 | `Ctrl/⌘ + A` / `Ctrl/⌘ + 点击` / `Shift + 拖动` |
| 自动排列 | `Shift + A` |
| 删除所选 | `Delete` |
| 全部运行 / 后台运行 | `Ctrl/⌘ + Enter` / `Ctrl/⌘ + Shift + Enter` |

## ⚙️ 设置配置

访问侧边栏中的 **设置** 标签页，微调自动化行为：

* **默认模式：** 设置打开时的默认创作模式。
* **默认宽高比：** 可选 16:9（YouTube）、9:16（Shorts/Reels）、1:1（正方形）、3:4（纵向）或 4:3（横向）。
* **每个提示词的输出数量：** 控制每个提示词生成的视频数量（1 到 4 个）。
* **每个提示词的图片输出数量：** 指定每个提示词生成的图片数量（最少 1，最多 50）。
* **并发提示词数：** 选择同时运行的提示词数量（1 到 6 个提示词）。
* **随机延迟：** 设置处理提示词之间的随机等待时间。
* **视频模型与图片模型：** 选择您希望用于生成视频/图片的特定 AI 模型。
* **默认视频/图片选项：** 设置默认时长或拼接模式（例如：5秒或5秒（拼接）以拼接视频；新图片或编辑图片模式以链式编辑图片）。
* **每个提示词的最大输入图片数：** 配置帧图生成视频、素材生成视频和图片生成图片的最大素材图片限制。
* **失败时最大重试次数：** 指定生成失败时的重试次数（1 到 20 次）。
* **自动下载质量：** 设置自动下载质量（不下载、视频为 1080p、图片为 1k）。
* **下载设置：** 自动将生成的输出分类整理到 Chrome 下载目录下独立的项目子文件夹中。
* **语言：** 在 English、Tiếng Việt、中文、한국어、Español 和 日本語 之间进行切换。

## 💡 提示与最佳实践

1. **应对限制：** 如果您的 Qwen 账户遇到速率限制，请增加设置中提示词之间的 **随机延迟**。
2. **最佳并发数：** 建议从 1 个并发提示词开始，并根据您 Qwen 账号的状态和性能逐步增加。
3. **拼接视频：** 使用设置中的 **5秒（拼接）** 选项，可以将连续的提示词输出拼接为一个长视频。
4. **项目文件夹命名：** 在控制标签页中为您的项目文件夹命名，以便将所有文件整洁地归类在一起。

## 🔧 故障排除

| 问题 | 解决方案 |
| :--- | :--- |
| **扩展程序未激活** | 确保您位于 [chat.qwen.ai](https://chat.qwen.ai)。如有需要请刷新页面（F5）。 |
| **生成错误** | 点击扩展程序界面上的 **修复错误** 按钮。扩展程序将根据设置的“失败时最大重试次数”自动尝试重新提交。 |
| **下载无效** | 请在 Chrome 浏览器设置中 **关闭** “下载前询问每个文件的保存位置”设置。 |
| **账号及授权问题** | 确认您已登录 `chat.qwen.ai` 以及扩展程序的方案账户（通过方案横幅）。 |
| **工作流：结果一直停在“生成中”** | Chrome 暂停了被遮住的 chat.qwen.ai 标签页。开启 **开启后台模式**（或 **后台运行**），或保持 chat.qwen.ai 标签页可见。 |
| **工作流：某个节点的运行按钮不可用** | 将鼠标悬停在按钮上：先运行它依赖的节点，或修复提示的问题（例如未连接提示词）。 |
| **工作流：全部运行不可用** | 点击顶部栏的 **问题 (n)** 查看需要修复的内容；点击某个问题可跳到对应节点。 |
| **工作流：“未找到 chat.qwen.ai 标签页”** | 在标签页中打开 [chat.qwen.ai](https://chat.qwen.ai)（顶部栏的绿点表示已连接）。 |
